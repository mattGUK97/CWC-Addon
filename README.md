# Coping with Caffeine (CWC) addon

The private guild addon for World of Warcraft: a shared roster with professions at a glance, and Kill on Sight and player blacklist requests that officers approve together.

## Install

1. Download `CWC-Addon.zip` from this repository, or use the download button on the CWC page.
2. Extract the `CWC` folder into `World of Warcraft\_forever_\Interface\AddOns\`.
3. Start the game, enable CWC on the addon list, and log in. Type `/reload` if it was already running.

## Layout

- `CWC/` — the addon itself (copy this folder into `Interface\AddOns`).
- `CWC-Addon.zip` — the same folder packaged for download.

Current version: see `## Version` in `CWC/CWC.toc`.
